# 快手 AI 漫剧生成流水线

用「免费优先」的多模型流水线，把《山海经》异兽做成 15-60 秒竖屏短视频——**分镜表驱动、每镜一个模型、段长跟配音走、免费兜底不重试**。

> 本仓库是方法论文档 + 可复用流水线脚本，**不含任何 API key**（全部走环境变量）。
> 完整方法见 [`docs/methodology.md`](docs/methodology.md)，赛道选择依据见 [`docs/benchmark-research.md`](docs/benchmark-research.md)。

## 成果（真实发布数据）

| 片子 | 时长 | 播放 | 平均播放时长 | 5 秒完播 | 完播率 | 互动率 |
|---|---|---|---|---|---|---|
| 糖画匠（第 1 条，民俗） | 58.2s | 3001 | 6.7s | 22.7% | 1.5% | 0.1% |
| 山海经·烛龙（第 2 条） | 53.1s | 2981 | **12.9s** | **45.6%** | **7.0%** | 0.2% |
| 山海经·白泽（第 3 条，待发布） | 39.6s | — | — | — | — | — |

第 2 条相对第 1 条：平均播放时长翻倍、5 秒完播翻倍、完播率 4.7 倍——**改开头 3 秒 + 换赛道**这两处动作的实测效果。

当前瓶颈不在留人（开头吸引力已被平台诊断为"强"），而在**互动率 0.2%**，第 3 条起针对它做改造。

## 流水线

```
① 定分镜表 + 文案（零额度）
        ↓
② 首帧图 ×8（同一图像模型 + 锁死形象常量）
        ↓
③ 视频段 ×8（每镜一个视频模型，失败落免费兜底，不重试）
        ↓
④ 配音 ×8（edge-tts 神经语音，旁白/角色用 rate+pitch 区分）
        ↓
⑤ 拼接合成（段长跟配音走 + 慢放补时长 + 交叉溶解 + 静音垫）
        ↓
⑥ 验收 + 发布（AI 双重标识 + 黄金时段 + 评论区运营）
```

派生下一只异兽只需换三样：分镜表 `SHOTS`、形象常量、`AI_META`。

## 快速开始

```bash
# 1. 依赖
pip install requests imageio-ffmpeg edge-tts
# ffmpeg 由 imageio-ffmpeg 自带，无需单独安装

# 2. 设置环境变量（不要把 key 写进文件）
export DASHSCOPE_API_KEY="..."   # 阿里云百炼（视频/图像模型）
export AGNES_API_KEY="..."       # Agnes（免费 keyframe 兜底）

# 3. 跑一条
python pipeline/make_video.py
```

脚本支持断点续跑：`urls.json` / `tasks.json` / `raw/` 缓存任何一步的产物，崩了重跑不会重复消耗额度。

## 三条硬规矩

1. **先免费后付费**——新片先用免费资源（免费 keyframe + edge-tts + 缓存）出全片，成片过目拍板后，才用付费额度**单点替换指定镜头**，每镜只出一次。
2. **每模型每镜只调一次**——额度不足或限流，直接落免费兜底，不重试、不换参数、不做 A/B 试片。付费额度是定稿工具，不是试验工具。
3. **当前成片封版**——对已发布视频的反馈只进下一版改进清单，不回头出修复版/多版本。
