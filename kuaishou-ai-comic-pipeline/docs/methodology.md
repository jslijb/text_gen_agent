# 快手 AI 漫剧生成方法总结（截至 2026-09-19）

> 来源：糖画匠（第一条，2026-09-16 发）、山海经烛龙（第二条，2026-09-16 发）、山海经白泽（第三条，已生成待发布）三条成片的完整实操复盘。数据依据见各日工作日志与后台截图。

## 一、赛道与账号定位

- **赛道**：AI 经典奇谈（快手官方光合大会明牌扶持的三大赛道之一，另两个是 AI 老铁真实故事、AI 脑洞百科）。
- **定位**：「AI 神话图鉴」——只做《山海经》等中国古典典籍里**有原文出处**的异兽，一条视频一只兽，系列化养号。现代网文自创妖怪、希腊北欧神话不做；被影视拍烂的人物（孙悟空类）后期再考虑。
- **为什么**：①算法靠一致性给账号打标签，混发不同类内容两边流量都起不来；②神话没人较真，写实题材有"假纪实"反感与举报风险；③对标账号（乔戈里漫剧涨粉榜第一周 72 万粉、动物世界体山海经 56 条 1.2 亿播放、山海异闻录单条 340 万赞）全部是"一个壳子反复用"。
- **出处即卖点**：每条描述引一句原文（烛龙条引"视为昼，瞑为夜"，《山海经·海外北经》），观众刷到的是"有根有据的古书异兽"。

## 二、单条视频的生产流程（已固化为脚本模板）

```
定分镜表+文案（零额度） → 首帧图 8 张 → 视频段 8 段 → 配音 8 句 → 拼接合成 → 验收
```

脚本：`.workbuddy/_make_zhulong_video.py`（模板）、`_make_baize_video.py`（派生例）。派生新兽只需换三样：分镜表 SHOTS、形象常量、AI_META，10 分钟出下一条。

1. **分镜表先行**：8 个分镜，每镜=画面描述（img）+ 视频提示词（vprompt）+ 旁白（line）+ 指定视频模型。**先定表再动手，一个模型认领一个分镜，禁止东一条西一条散测烧额度。**
2. **首帧图**：8 张全部用同一个图像模型（qwen-image-2.0-pro-2026-06-22，100 次额度）+ **锁死同一段形象描述常量** + 统一画风后缀——首帧决定画面风格八成，是跨模型一致性的根基。
3. **视频段**：r2v 类模型把该镜首帧当参考图喂进去锁主体；每模型只调一次，报额度不足/429 **直接落 Agnes 免费 keyframe 兜底，不重试**。
4. **配音**：edge-tts 神经语音 `zh-CN-YunxiNeural`（云希男声，免费），旁白 rate=-5%；角色台词用 rate/pitch 区分（如角色 rate=-12%、pitch=-8Hz），台词字幕单独样式。脚本 `_make_voice_edge.py`，输出 44100Hz 单声道 wav。**已弃用 SAPI（Huihui 机械女声，听感差）**。
5. **拼接合成**：见第四节防卡顿方法。
6. **断点续跑**：urls.json / tasks.json / raw 缓存，任何一步崩了重跑不重复烧额度。

## 三、文案方法（完播与互动导向）

- **总长 15-60 秒**（快手完播友好区），8 镜 × 约 6-7 秒。
- **前 5 秒双钩子**：钩子不靠文案编，靠设定本身的反常识（烛龙：睁眼为昼/闭眼为夜连打两镜）。糖画匠开头慢热是反面教材（5 秒完播 22.7%），烛龙修后 45.6%，翻倍。
- **旁白每镜一句**，句子长度以 SAPI 实测为准——文案长度直接决定段长，8.15 秒的句子会把总长顶到 71 秒。
- **中段埋互动**：直呼观众（"屏幕前的你，认识几个？"）。
- **结尾行动指令 + 系列预告**："点赞收藏，白泽保你逢凶化吉；明天讲九尾狐"——给中老年观众一个明确动手理由，顺带预告引流关注。
- **发布描述**：原文出处 + 白话讲解 + 站队式提问，标签挂赛道 #山海经 #XX兽 #AI经典奇谈 #神话（逐个敲 # 从候选里选）。

## 四、合成与防卡顿（白泽流畅版定型）

三个卡顿根因与修复（糖画匠 59s 版的教训）：

| 问题 | 根因 | 修复 |
|---|---|---|
| 段尾死寂"憋一下" | 段长强行统一，配音最短 4.12s 挂 3 秒静音 | 段长跟配音走（配音+0.6s） |
| 画面循环跳变 | 5s 素材硬拉 7.36s，超出部分从头重播 | setpts 慢放拉伸补齐（1.14-1.44 倍，贴史诗感） |
| 段间硬切生硬 | 上一段结束下一段开始直接切 | xfade 0.5s 交叉溶解 + 音频处理见下行 |
| 字头被吞、停顿怪 | 音频 acrossfade 把每段开头 0.5 秒人声淡入了 | 每段人声前垫 0.5s 静音（adelay），淡化只落在静音上，字头完整 |

脚本 `_make_baize_smooth.py`。**改文案后必须删 voice 对应文件 + 全部 clips 缓存再重跑**（旧缓存是旧段长）。

**AI 双标识**：画面右上角"AI生成"显式角标 + 文件元数据（title/artist/comment/genre/description）隐式标识；发布页再勾"AI 生成"声明，三重合规。

## 五、模型额度纪律

- **模型 ID 必须全称带日期后缀**（wan2.7-r2v-2026-06-12，一字不差），对话/脚本/文档一律如此。
- **先烧快到期的**：按到期日排优先级（如 happyhorse 三支 9/21 到期先用，9/30 到期的次之，11 月的留后）。
- **每模型每镜只调一次**；失败落 Agnes 免费 keyframe 兜底，不重试、不等、不换参数再试。
- **额度纪律**：多把 key 分开记账。**key 只从环境变量读进脚本（os.environ），不写进文件、不打印、不外传**（本仓库脚本已全部改为环境变量读取，无明文 key）。
- **先免费后付费（2026-09-19 定）**：新视频一律**先用免费资源出全片**——视频段走 Agnes 免费 keyframe、配音走 edge-tts、素材优先复用缓存——成片给人过目、拍板之后，才用付费额度**单点替换指定镜头**，且每镜只出一次。禁止一上来就烧付费额度，也禁止用付费模型做 A/B 试片。
- **版本纪律（同上一并定死）**：对已出成片的反馈（声音、画面、节奏）**只记入下一版改进清单，不回头给当前视频出修复版/多版本**。付费额度是**定稿工具，不是试验工具**。

## 六、发布与运维（发布 10 分钟比发布本身重要）

1. **时段**：19:00-20:00 发布（自己后台观众画像：19-24 点最活跃）。周末白天有小坡但晚高峰仍是最高，冷启动看的是发布后头 2 小时，所以 19 点发＞16-17 点＞中午＞深夜。
2. **通道**：电脑 cp.kuaishou.com 上传（无压缩），扫码登录。
3. **封面**：选画面冲击最强一帧，右下角不放字。
4. **活动/话题**：发布页"为你推荐"位平台主动喂的匹配话题优先挂；名称含影视剧二创等不对口活动宁可不挂（挂错拖数据）。
5. **发布后 5 分钟**：自己评论站队式/扣 1 式问题并置顶；视频分享微信朋友圈/群拉真实完播；评论秒回。
6. **节奏**：日更 1 条，最多 2 条（间隔 4 小时+），**不断更是铁律**；新号前 10-20 条不做账号结论，只看单条指标。

## 七、数据复盘闭环（每条 24h 后执行）

对照五维诊断图：开头吸引力（5 秒完播）、观众互动率、流量、封面点击、涨粉。健康值：点赞率 3%+、完播率 30%+（新号起点远低于此属正常，看趋势）。

已验证的因果：糖画匠→烛龙，开头 3 秒修复后均播 6.7→12.9s、5 秒完播 22.7%→45.6%、完播率 1.5%→7.0%。**当前卡点是互动率（0.2%），不是留人**——白泽条的三处互动修改（直呼观众/点赞指令/扣 1 置顶）就是针对它的对照实验。

## 八、演进方向：从"讲故事"到"漫剧"

对标形态是角色对话+剧情冲突+字幕台词（见 `快手AI漫剧短剧对标调研报告.md`），九尾狐起改三处：

1. **角色台词做主（7 成），旁白只做串场（3 成）**——剧情里让角色开口，台词单独字幕样式，配音用语速/音高区分旁白与角色（系统仅一个语音包）。
2. **剧情逐段推进**：8 段是一条故事线（遇妖→危局→现身→辨妖→化解），不是并列空镜，每段结尾留半句钩子。
3. **结尾开放式悬念**引流关注，不再收束。

选择依据：这个形态同时喂饱完播、互动、静音观看三个指标，且"角色对峙开口"是低运动量镜头，正好躲开视频模型大幅动作易崩、无法对口型的短板。

## 九、踩坑记录（复现时必查）

- 配音文件 **0 起始编号**（v00-v07），按 1 起始删会删错对象→字幕口播错位，删前实测 wav 时长。
- PowerShell Remove-Item 会**静默失败**，删缓存用 Python 删并当场 listdir 验证。
- ffmpeg 链尾无参 `apad` 会把音频无限延长，ffmpeg 挂死——必须加 `-t` 总时长。
- xfade 链第二段起要接上一级输出标签（vx{i-1}），不是原始输入。
- 后台任务诡异死亡：改前台跑 + 输出全落盘（print 加文件日志防缓冲丢失）。
- OSS 直链下载 403：URL 签名参数不能被 strip。
- **本机 aiodns(c-ares) 损坏**：任何 aiohttp 系客户端（edge-tts 等）DNS 全挂，报 "Could not contact DNS servers"。修复：连接建立前 `aiohttp.connector.DefaultResolver = aiohttp.resolver.ThreadedResolver`（必须改 connector 模块里绑定的名字，改 resolver 模块无效）。
- **编辑脚本后必须断言复核落盘**（py_compile + assert 关键行在源码里）——本机出现过 Edit 报成功但内容没写进文件的情况，导致后台跑的仍是旧逻辑。
