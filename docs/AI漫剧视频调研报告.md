## 第一部分：各平台对AI生成视频的态度和规则

### 1. 抖音

| 维度 | 详情 |
|------|------|
| **是否允许发布** | 允许，但需遵守规范 |
| **是否需要标注** | **必须标注**。2023年9月抖音率先发布《关于AI生成内容的平台规范》，要求AI生成内容必须添加显著标识"AI生成"/"由AI生成" |
| **封号风险点** | ①未标注AI生成内容 ②用AI生成虚假新闻/谣言 ③用AI冒充真人 ④批量低质AI内容刷量 ⑤AI生成侵权内容 |
| **AI漫剧/短剧规则** | 抖音短剧频道允许AI漫剧发布，但需标注AI生成；不能以AI生成内容冒充真人拍摄短剧；短剧需通过内容审核（不含违规/低俗内容） |
| **版权归属** | 平台社区规范规定AI生成内容不享有与真人原创内容同等的版权保护，创作者需对AI生成内容承担法律责任 |

**关键政策文件**：
- 2023年9月：《抖音关于AI生成内容的平台规范暨行业倡议》
- 2024年3月：进一步明确AI生成内容标识要求，发布者需在视频画面或文案中添加"AI生成"标识

### 国家层面统一规定（核心依据）

**《互联网信息服务深度合成管理规定》**（国家网信办，2023年1月10日施行）：
- 深度合成服务提供者必须对AI生成内容添加**显著标识**
- 不得利用深度合成服务制作/发布虚假信息
- 违者可处1万-10万元罚款，情节严重可吊销许可

**《生成式人工智能服务管理暂行办法》**（2023年8月15日施行）：
- 生成式AI服务提供者需对生成内容进行标识
- 不得生成违法内容
- 需承担内容管理主体责任

## 第三部分：合规建议

### 1. 如何在各平台安全发布AI生成视频（不被封号）

#### 必须做的事（红线）

1. **必须标注"AI生成"**：所有平台都要求，这是国家法规强制规定
   - 抖音：视频画面或文案中添加"AI生成"标识
   - 快手：使用平台AI标注功能
   - 微信视频号：文案中声明AI生成
   - 长视频平台：视频开头/信息中标注

2. **内容必须合规**：
   - 不得生成虚假新闻/谣言
   - 不得生成低俗/色情/暴力内容
   - 不得冒充真人（尤其是公众人物）
   - 不得侵犯他人肖像权/名誉权

3. **确保素材版权**：
   - 使用开源/免费素材（Pexels/Pixabay等）
   - AI生成的画面需确认不侵犯训练数据中的版权
   - 配音/音乐需使用授权素材

#### 建议做的事（加分项）

4. **提升内容质量**：低质AI内容会被限流，需人工审核+修改
5. **不要纯AI发布**：加入人工创作元素（剪辑、配音、创意），降低被判定为"低质AI"的风险
6. **控制发布频率**：避免批量发布导致刷量判定
7. **建立原创品牌**：持续输出高质量AI漫剧，建立粉丝基础
8. **多平台分发**：快手对AI内容最友好，抖音流量最大，视频号需谨慎

#### AI漫剧/短剧专项建议

9. **短剧需有完整剧情**：纯AI画面拼接容易被判低质，需要有完整故事线
10. **配音质量要高**：使用高质量TTS或真人配音，AI配音需标注
11. **画面风格统一**：AI漫剧需保持画风一致性，避免跳帧/风格突变
12. **时长控制**：短视频平台1-3分钟为宜，长视频平台可做5-15分钟

### 2. 推荐的开源技术方案组合

#### 方案A：AI漫剧全流程（推荐）

```
小说文本 → [LLM拆分章节/场景] → [AI图片生成] → [TTS配音] → [字幕生成] → [FFmpeg合成视频]
```

| 环节 | 推荐方案 | 备选方案 |
|------|---------|---------|
| 剧本/场景拆分 | Qwen3.7-max / DeepSeek | GPT-4 / Kimi |
| 图片生成 | Stable Diffusion / FLUX | Midjourney(付费) / DALL-E(付费) |
| 图片→视频片段 | CogVideoX-5B-I2V | Wan2.1 / SVD |
| 配音 | ChatTTS / Edge TTS | Azure TTS / Fish-Speech |
| 字幕 | Whisper / faster-whisper | Edge TTS时间戳 |
| 背景音乐 | Sonilo AI / 免费音乐库 | Suno(付费) |
| 视频合成 | FFmpeg + MoviePy | MoneyPrinterTurbo |
| 全流程编排 | NarratoAI | MoneyPrinterTurbo |

#### 方案B：短视频自动生成（快速出片）

```
主题/关键词 → [MoneyPrinterTurbo] → 成品短视频
```

直接使用MoneyPrinterTurbo，一键生成短视频，适合知识科普/情感/资讯类内容。

#### 方案C：影视解说/短剧混剪

```
视频素材 → [NarratoAI] → 解说+剪辑+配音+字幕 → 成品
```

使用NarratoAI，支持短剧混剪、影视解说、语音克隆。

### 3. 从小说文本到成品视频的完整Pipeline

```
┌─────────────────────────────────────────────────────────────────┐
│                    AI漫剧生成完整Pipeline                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  1. 文本处理层                                                   │
│     小说全文 → LLM拆分为章节 → 每章拆分为场景                     │
│     每个场景生成: 场景描述 + 对话 + 旁白 + 画面提示词              │
│     (使用Qwen3.7-max / DeepSeek)                                │
│                                                                 │
│  2. 画面生成层                                                   │
│     场景描述 → 图片生成(Stable Diffusion/FLUX)                   │
│     → 保持角色一致性(IP-Adapter/ControlNet)                      │
│     → 图片转视频片段(CogVideoX-I2V, 每段5-10秒)                 │
│                                                                 │
│  3. 音频生成层                                                   │
│     对话/旁白 → TTS配音(ChatTTS/Edge TTS)                       │
│     → 语音克隆(可选, IndexTTS/Fish-Speech)                      │
│     → 背景音乐(Sonilo AI / 免费BGM库)                           │
│                                                                 │
│  4. 合成层                                                      │
│     视频片段 + 配音 + 字幕(Whisper) + BGM                       │
│     → FFmpeg/MoviePy合成                                        │
│     → 添加"AI生成"水印标识                                       │
│     → 输出成品MP4                                                │
│                                                                 │
│  5. 分发层                                                      │
│     → 各平台发布(需标注AI生成)                                   │
│     → 抖音/快手: 竖屏9:16                                       │
│     → 优酷/爱奇艺/腾讯: 横屏16:9                                │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

#### 关键技术难点与解决方案

| 难点 | 解决方案 |
|------|---------|
| 角色一致性 | 使用IP-Adapter + ControlNet保持角色面部/服装一致；或使用LoRA微调固定角色 |
| 画面连贯性 | CogVideoX生成5-10秒片段，用场景过渡（淡入淡出/转场）连接 |
| 配音自然度 | ChatTTS音质较好，Edge TTS免费可用；关键角色可用语音克隆 |
| 批量生产 | MoneyPrinterTurbo/NarratoAI支持批量，可自建Celery异步任务队列 |
| 合规标注 | 合成时自动添加"AI生成"水印，文案中声明 |
